# IS-219-Prototype-Little-Baby
Lage en side for Little Baby, fokus på foreldrepar(foreldrekonto)

## Sider
- `pages/index.html` – velkomstside for Little Baby.
- `pages/innlogging.html` – innlogging for foreldrene.
- `pages/min-side.html` – personlige lister, huskelister, kalender og innhold delt med deg.
- `pages/foreldreprofil.html` – forelderens profil og innstillinger for deling.
- `pages/barnets-side.html` – felles informasjon om barnet.

## Felles filer
- `css/style.css` – utseende for sidene.
- `js/script.js` – funksjonalitet for sidene.
